## 3. 의도적으로 남아 있는 보류 항목

1. `selectManualLayout()`과 `availableManualLayouts`는 구현돼 있으나 호출자 0이다. 이는 자동 구도 데모 범위에서 수동 레이아웃 피커를 보류한 결정이며, AI 2·AI 3 재개와는 독립이다.
2. EfficientDet이 초기화/추론에 실패하면 ML Kit 객체 검출로 되돌아가지 않는다. 성능을 위한 오너 결정이므로, 실패율은 실제 기기에서 별도로 판정한다.

- 앱 실행 → 첫 프리뷰/첫 레이아웃 2초 이내

- 중앙 물체 1·2·3개, 인물+물체, 주변 모니터/케이블 장면의 슬롯 수
- 재탐색 뒤 이전 고정이 해제되는지
- 셔터 → 결과 자동 보정 → 저장 → 앨범 왕복을 3회 연속 성공하는지
