# P1 긴급 연결 요청 — QR·내 감도·온디바이스 가이드

> 2026-07-31 · P2가 서버/상태 경계를 정리한 뒤 전달하는 최소 UI 연결 요청이다.
> 회귀 테스트는 P1의 통합·시연 단계에서 수행한다. 이 문서는 새 시각 스타일을 지시하지 않는다.

## 현재 P2 상태

- CAMP-2 FastAPI와 `gamdo-web`을 현재 main 소스로 재배포했다.
  - `GET /health`은 200이다.
  - `POST /api/v1/shoot-sessions`은 V2 정책을 보존한다.
  - `GET /shoot/{token}`과 `GET /api/v1/shoot-upload/{token}/config`은 동작한다.
- Android `CameraScreen`에는 `onOpenDelegatedShoot: (GuideLayoutState) -> Unit` 연결점이 있다.
- 올가미는 `POLYGON`에서 앵커 클러스터를 쓰지 않고, 영역 안의 안정 객체 전체(최대 4개)를 반환하도록 P2가 수정 중이다.

## P1이 연결할 항목

### 1. QR ‘나 찍어줘’ 진입

카메라에서 사용자가 직접 누르는 공유 진입점 하나를 추가한다. 위치·아이콘·시트 디자인은 P1이 결정한다.

```kotlin
onOpenDelegatedShoot(layoutState.value)
```

- 자동 호출·카메라 진입 시 호출 금지.
- `Searching`이면 버튼을 막지 말고, P2 화면이 제공하는 `NoLayout` 상태에서 수동 프레임 선택 또는 취소로 이어지게 한다.
- `Fixed`면 현재 고정 가이드를 그대로 QR 정책으로 보낸다.
- QR 화면은 서버 배포 완료 상태이므로 과거의 “웹 미배포/503” 문구나 숨김 조건을 제거한다.

### 2. 내 감도 참조 이미지 투명도

- 카메라의 활성 `내 감도`에 참조 원본이 존재하는 현재 세션에서는 `ReferenceOverlayLayer(alpha, onAlphaChange)`를 표시한다.
- 투명도 UI는 `overlayAlpha` 단일 상태를 읽고 `onAlphaChange`만 호출한다. 필터 선택 상태나 시트 닫힘으로 값을 다시 초기화하지 않는다.
- 유효 범위는 `0.00..0.60`, 기본 `0.30`이다.
- 참조 원본이 없는 재실행 세션은 색감/구도 스타일은 유지하되 사진 오버레이만 숨긴다. 없는 이미지를 더미로 보이지 않는다.
- P1은 이 제어를 기존 포커스·핀치·올가미 터치 표면 위에 별도 전체 화면 pointer handler로 올리지 않는다. 작은 실제 컨트롤만 소비해야 카메라 제스처가 유지된다.

### 3. 올가미 연결

- 기존 `영역 선택` 진입·그리기·취소는 유지한다.
- 완료 시 P2 `rescanInPolygon()`을 한 번만 호출하고 `Searching` 동안 작은 로딩을 표시한다.
- 결과 슬롯 수 `1..4`를 그대로 렌더링한다. UI에서 첫 슬롯 하나만 골라내거나 객체 종류별로 다시 합치지 않는다.

## P1 시연 확인 항목

1. 고정 레이아웃이 있는 상태에서 QR 진입 → QR 생성 → 다른 휴대폰에서 웹 카메라가 열린다.
2. 웹에서 한 장 촬영 → 소유자 앱 QR 화면의 도착 사진 수가 증가 → 받기/claim 후 앨범 결과로 열린다.
3. 내 감도 선택 후 투명도 조절이 사진 오버레이에 즉시 반영되고 필터 스트립은 사라지지 않는다.
4. 올가미 안의 분리된 2~4개 객체가 각각 가이드로 표시되고, 바로 밖 객체는 표시되지 않는다.

## 경계

- P2: QR 서버·정책·수신, 투명도 상태/렌더 콜백, 객체·올가미 결과.
- P1: 진입 버튼, QR/투명도/올가미의 실제 화면 배치·아이콘·애니메이션·시연 흐름.
