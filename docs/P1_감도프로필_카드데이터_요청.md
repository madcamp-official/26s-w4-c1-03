# P1 요청 — 상황별 감도 프로필 카드 데이터

## 목적

P2의 `CardRecommendationEngine`은 첫 12장, 추가 12장, 선택적 마지막 8장(총 32장 이하)을 사용자 반응과 불확실성에 따라 구성한다. 카드가 다양하지 않으면 "상황별 감도"가 같은 사진을 반복 제시하는 기능으로 축소된다.

## P1 제공물

각 카드에 아래 메타데이터를 `cards.json`에 추가하거나 별도 manifest로 제공해 달라. 이미지 자체의 출처·사용 조건도 기록한다.

| 축 | 필요한 값 예시 |
|---|---|
| 구도 | 피사체 크기, 좌우 앵커, 상단 여백, 배경 비율, 프레이밍 |
| 색감 | 밝기, 색온도, 채도, 대비, 선명도, 그레인 |
| 조명·질감 | 자연광/플래시/야간, 필름/저채도/고대비/모션 |
| 장면 | 인물, 전신 로우앵글, 근접 인물·셀피, 카페·음식, 정물, 풍경 |
| 출처 | `source`, `license`, `demoOnly` |

필수 범주: Pinterest 에디토리얼, Instagram 소셜·캐주얼, 블로그 리뷰·음식, 직접 플래시·야간, 항공샷·플랫레이, 의도적 흔들림·모션, 필름·저채도·고대비, 전신 로우앵글, 넓은 배경 인물, 근접 인물·셀피, 카페·정물·풍경, 추가 트렌드 감성.

## 연결 계약

- 카드 수가 아직 16장이라면 P2 엔진은 같은 카드 중복 없이 축소 동작한다.
- 사용자는 5장 이상 선택하면 저장 가능하다. 추가 묶음은 선택 사항이다.
- 새 카드 추가는 P2 코드 변경 없이 manifest 로드 경로로 반영 가능해야 한다.
- 기존 온보딩·카메라 화면의 시각 디자인은 P1 소유다.
