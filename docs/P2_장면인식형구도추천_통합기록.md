# P2 장면 인식형 구도 추천 통합 기록

## 기록일

2026-07-27

## 2차 구현 기록 — 장면 맞춤 레이아웃 가이드

기존 `SceneProposalEngine`이 목표 프레임 위치만 바꾸던 한계를 보완했다.

- `SceneLayoutGuideEngine` 추가
  - `STATIC`: 피사체 미검출·낮은 신뢰도. 정적 프레임과 `피사체를 화면에 보여주세요` 안내
  - `DETECTING`: 피사체는 보이지만 신뢰도가 낮음. 감지 박스와 `피사체를 잠시 유지해주세요` 안내
  - `CONFIDENT`: 피사체 윤곽을 추천 구도 안으로 투영한 고스트 가이드 표시
- 인물은 포즈 랜드마크의 convex hull을 사용하고, 일반 물체는 감지 바운딩 박스를 사용한다.
- 기존 목표 브래킷과 세이지 색상 전환은 유지하며, 새 윤곽은 기존 오버레이 위에 기능적으로만 추가했다.
- 요청에 따라 안내 문구를 추가했으므로, 기존 D2의 텍스트 안내 금지 결정은 이 기능 범위에서 오너 요청으로 예외 처리했다.

## 수정 범위

P2에서 구현한 장면 인식형 구도 추천을 기존 카메라 분석 흐름에 연결했다.

이번 변경은 P1 화면의 레이아웃·색상·타이포그래피·컴포넌트 배치를 수정하지 않고, 다음 기능 영역만 수정했다.

- `CameraScreen`: 얼굴·포즈 detector에 물체 detector와 throttling 경로 추가
- `CameraScreen`: Y 평면 구조 신호(`rowLuminance`, `sideEdgeDensity`) 전달
- `CameraViewModel`: `SceneGuideCoordinator` 호출 및 장면별 `StyleTarget` 적용
- `CameraViewModel`: 물체 피사체 박스를 `AlignmentEngine` 정렬 입력으로 전달
- `CameraViewModel`: 분석 디버그 라벨에 물체 검출 개수 추가

## 런타임 흐름

```text
CameraX ImageProxy
→ ML Kit 얼굴·포즈·물체 검출
→ 물체 검출 3프레임 throttling
→ Y 평면 수평선·좌우 빈 공간 신호
→ SceneGuideCoordinator
→ SceneProposalEngine 후보 선택
→ AlignmentEngine
→ 기존 브래킷·실루엣·수평선 오버레이
```

## 미검증

- 실기기에서 ML Kit object detection 모델 최초 다운로드
- 실제 물체·인물·수평선 장면별 오버레이 시각 품질
- ML Kit 객체 인식 모델이 준비된 실기기에서 안내 문구·투영 윤곽·프레임 정렬이 사용자에게 유용한지 여부
- SM-S928N의 분석 FPS·프리뷰 지연·발열
- 카메라 권한·렌즈 전환·화면 재구성 후 detector lifecycle

## 제품 규칙 준수

- 텍스트 지시 문구·화살표·일치도 점수·자동 촬영을 추가하지 않았다.
- 생성된 구도 후보 점수는 내부 판단에만 사용한다.
- 물체 검출 실패 시 기존 스타일 프리셋 구도로 폴백한다.
