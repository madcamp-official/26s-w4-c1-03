# 감도 폐쇄 데모 데이터·운영 계약

> **기준일:** 2026-07-28
> **적용 범위:** AI 2(내 감도 만들기), AI 3(사진 살리기), CAMP-2 품질 검증
> **우선순위:** `remain_plan.md` §0 O-8과 `AGENTS.md` D8을 구체화한다.

## 1. 목적

감도는 폐쇄형 토이프로젝트 데모다. 개인정보 보관·삭제 규칙이 분석·생성 기능의 구현, 품질 비교, 실기기 시연을 막지 않도록 한다. 이 문서는 공개 서비스용 개인정보 정책이 아니며, 배포 전에는 별도 정책으로 다시 교체한다.

## 2. 허용되는 데이터와 보관

사용자가 직접 선택하거나 `사진 살리기`를 실행한 경우 다음을 CAMP-2 GAMDO 작업공간과 앱 로컬 캐시에 보관할 수 있다.

- 레퍼런스 원본·정규화본·썸네일
- 편집 입력, 마스크, ComfyUI 중간 산출물, 후보 결과
- 분석 응답, 객체 수·레이아웃·색감 파라미터, 작업 시간과 오류 로그
- 품질 비교를 위한 얼굴 탐지 결과·임베딩·분할 결과

보관 기간은 데모·품질 개선이 끝날 때까지이며, 자동 삭제·24시간 만료·즉시 purge는 요구하지 않는다. 사용자가 앱 데이터를 초기화하거나 수동 정리를 요청하면 해당 범위에서 정리한다.

## 3. 처리 규칙

- AI 2와 AI 3 업로드는 사용자의 사진 선택 또는 실행 버튼 뒤에만 일어난다.
- 라이브 카메라 프레임은 실시간으로 서버에 전송하지 않는다.
- EXIF 제거·방향 보정·축소는 가능한 경우 적용한다. 어느 하나가 실패해도 데모 파이프라인은 실패시키지 않는다.
- 재시도 파일·원본 오버레이·분석 캐시의 만료 정책은 성능과 재현성을 우선해 구현 시 조정할 수 있다.
- 계정, 공개 URL 공유, 외부 제3자 AI API 자동 전송은 이 계약에 포함하지 않는다.

## 4. 생성 결과 검증

다음은 항상 검사한다.

- 결과 파일이 실제로 디코드되는지
- 기대한 크기·방향인지
- 결과 파일이 입력 원본을 그대로 가리키지 않는지
- 아웃페인팅에서 원본 내부 픽셀이 보존되는지

다음은 후보 품질을 비교·정렬하는 데 사용하며 단독 실패로 결과를 숨기지 않는다.

- 얼굴 수·얼굴 유사도
- 히스토그램 변화량·경계 이음새
- 객체·포즈·분할의 신뢰도

얼굴·신체를 의도적으로 바꾸는 기능은 제품 범위 밖이다. 이 제한은 데모 데이터 보관을 제한하는 근거로 사용하지 않는다.

## 5. 수동 정리 기준

다음 중 하나가 끝나면 리드가 CAMP-2 GAMDO 작업공간과 해당 테스트 기기의 앱 데이터를 함께 정리할지 결정한다.

1. 데모 리허설 종료
2. 사용자 요청
3. 서버 저장 공간 부족
4. 공개 배포 준비 시작

정리 전에는 필요한 품질 측정값과 재현 명령만 문서에 남기고, 원본 사진을 외부 문서·이슈·공개 저장소에 복사하지 않는다.
