## 4. 우선 수정 목록

### P0 — 다음 구현 순서

1. **M10 자동 기본 보정 완성:** 촬영 센서값과 `ImageMetricsExtractor`를 사용해 노출·대비·색온도 자동값을 산출하고, 수평/크롭 최소 구현을 비파괴 스택에 기록한다.
2. **M13 결과 상태 완성:** 원본/기본/스타일/생성 4트랙, 진행 상태, 편집 단계 되돌리기와 OS 공유를 추가한다.
3. **M7 앱 연결:** 레퍼런스 선택·서버 전송 고지·로컬 캐시·TargetComposition 오버레이·색감 적용까지 연결한다.
4. **M6 장면 제안 최소 구현:** 정적 프리셋만 쓰지 않고 인물 위치·여백·수평을 입력으로 규칙 3개(배치/수평/여백) 중 하나를 선택하도록 한다.
5. **M9 세션 기록:** 촬영 순간 FrameFeatures·내부 일치도·활성 프리셋을 로컬 sessions/captures에 기록한다.

### P1 또는 외부 의존 — 이번 프로토타입에서 별도 판정

- 실제 인물 5쌍 InsightFace 임계값, 큐레이션 카드 이미지 라이선스·20장 확장, 망한 사진 10장 품질 기준.
- MediaPipe 분할·자동 방해물 마스크, 포즈 템플릿, FLUX.1 Fill 아웃페인팅, IC-Light.
- 다인 추적·리딩 라인·개방 공간·일반 객체 감지, 실제 인물 프레임 오버레이 정렬/색 전환 튜닝.
- 플래시/촬영음/물리 렌즈, 전체 해상도 보정 2초 성능 계측, 핀치 줌 기기별 회귀.
