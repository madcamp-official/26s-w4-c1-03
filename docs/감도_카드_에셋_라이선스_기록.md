## 승인 조건

각 최종 에셋에 대해 출처 URL, 제작자, 라이선스 문구, 확인일, 원본 다운로드 또는 허가 증빙을 채운 뒤 검토한다. 증빙이 없는 파일은 앱 데모에는 사용할 수 있지만 외부 배포 APK나 발표 자료의 대표 이미지로 사용하지 않는다.

대체 에셋을 받을 때는 파일 교체와 함께 이 표를 갱신하고, `cards.json`의 카드 특성과 이미지 내용이 일치하는지 별도로 확인한다. 이미지 SHA-256은 교체 후 다시 계산한다.
