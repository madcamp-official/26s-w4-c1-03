13장을 피사체가 다른 사진으로 교체하고 인물 3장(card_01·02·04)은 유지했다.
후보는 슬롯당 3장씩 39장을 모았고, 최종 1장은 **측정값과 슬롯 목표의 거리**로
골랐다. 사람이 취향으로 고른 것이 아니다.

### 대표 색 측정 (colorA · colorB)

계산 정의 — 재측정이 필요하면 이대로 따른다:

1. 최종 에셋(768×1024) 전체 픽셀을 **리사이즈 없이** 읽는다
2. sRGB 8비트 → 0..1 → sRGB 역감마(`v ≤ 0.04045 ? v/12.92 : ((v+0.055)/1.055)^2.4`) → 선형 RGB
3. 선형 RGB → CIE XYZ (sRGB 원색 행렬), 백색점 D65 `(0.95047, 1.00000, 1.08883)`로 정규화
4. XYZ → CIELAB
5. **전체 픽셀의 a\*, b\* 산술평균.** 소수 둘째 자리 반올림 → `colorA`, `colorB`

같은 파이프라인의 L\* 평균은 기존 `brightness` 열과 전 16장에서 −0.007 ~ +0.039 안에서
일치한다(즉 `brightness ≈ L*/100`). 새 측정이 기존 실측 축과 같은 정의 위에 있다는 확인이다.

**추가 이유.** `colorTemperature`는 사진의 색이 아니다. 플랑크 궤적(흑체 복사) 위의 한 점,
즉 **주황↔파랑 한 축**이고 초록은 그 축 위에 없다. 1500 K~12000 K 전 구간을 훑어도
`max(G − max(R, B)) = 0.0000`이라 초록이 우세한 색은 만들어지지 않는다. 그래서 온보딩
스와치가 어떤 선택에도 회색으로 나왔다(오너 보고 2026-07-30, 재현 완료). 대립색 좌표는
그 한계가 없고, 선택이 서로 반대면 자연스럽게 상쇄되어 중성이 된다.

측정 스크립트는 저장소에 남기지 않았다. 위 정의로 재작성한다.

기하 값을 측정하지 않은 이유: 스펙트럴 레지듀얼 세일리언시로 피사체 크기를 재려
했으나 실패했다. 이 방식은 고주파 질감에 반응하므로 질감이 많은 바다 사진이
매끈한 커피잔 클로즈업보다 큰 값을 받았다 — 실제와 반대다. 바운딩 박스 방식과
농도(saliency mass) 방식 둘 다 같은 문제를 보였다. 의미적 피사체 검출이 필요하며,
그때까지는 설계값이 더 정확하다.
